# Product List & Shopping Cart

A simple shopping cart application built using **HTML, CSS, and JavaScript**. Users can add products to their cart, remove items, view the total price, and keep their cart data even after refreshing the page using **Local Storage**.

## Features

* Display a list of products
* Add products to the cart
* Remove items from the cart
* Calculate and display the total price
* Persist cart data using Local Storage
* Checkout functionality to clear the cart
* Dynamic UI updates using DOM manipulation

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API

## How It Works

1. Products are displayed dynamically from a JavaScript array.
2. Clicking **Add to Cart** adds the selected product to the cart.
3. Cart items are stored in Local Storage to persist data across page refreshes.
4. Users can remove individual items using the **Remove** button.
5. The total cart value updates automatically.
6. Clicking **Checkout** clears both the cart and Local Storage.
